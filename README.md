# 🛍️ Digital Store

Projeto de uma loja virtual desenvolvido a partir de um projeto disponibilizado pela Digital College, com modificações e personalizações realizadas durante meus estudos em desenvolvimento Front-end.

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- Vite
- HTML5
- CSS3

## ✨ Funcionalidades

- Interface de loja virtual.
- Exibição de produtos.
- Navegação entre páginas.

## 💻 Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/tamiresfreitas/projeto-digital-store.git
```

2. Entre na pasta:

```bash
cd digital-store
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

## 📚 Projeto original

Este projeto foi baseado no repositório [Digital College - Projeto Digital Store](https://github.com/digitalcollegebr/projeto-digital-store).

As modificações e personalizações foram realizadas para fins de aprendizado e desenvolvimento de habilidades em React e desenvolvimento web.
